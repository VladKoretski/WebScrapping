# Парсер статей Habr

Скрипт для парсинга свежих статей с Habr.com с фильтрацией по ключевым словам. Учебные проект.  

**Студент:** *Корецкий В.П.*

## Описание

Данный скрипт автоматически собирает статьи со страницы свежих публикаций Habr, анализирует их заголовки и превью-текст, и отбирает только те статьи, которые содержат заданные ключевые слова. Результат сохраняется в файл `parsed_pages.json`.

## Задача

Парсить страницу со свежими статьями Habr и выбирать статьи, в которых встречается хотя бы одно из ключевых слов. Поиск ведется по всей доступной preview-информации (заголовок + краткое описание).

## Возможности

- Автоматический парсинг статей с Habr.com
- Фильтрация по ключевым словам (регистронезависимый поиск)
- Извлечение заголовка, даты, превью-текста и ссылки
- Сохранение результатов в JSON-формате
- Headless-режим (работа без открытия окна браузера)
- Автоматическая установка и обновление ChromeDriver
- Обработка динамического контента с помощью Selenium

## Требования

- Python 3.7+
- Google Chrome (последняя версия)
- Установленные зависимости из `requirements.txt`

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd <project-directory>
```  
  
Установите зависимости:  

bash
```
pip install -r requirements.txt
```

Настройте конфигурацию в файле config/config.py:

python
URL = "https://habr.com/ru/articles/"
CONTENT_BLOCK = "div.tm-articles-list"
ARTICLE_BLOCK = "article.tm-articles-list__item"
ARTICLE_TITLE = "h2.tm-title a.tm-title__link"
ARTICLE_BODY = "div.tm-article-body"
KEYWORDS = ['дизайн', 'фото', 'web', 'python']

## Детали реализации
Основной алгоритм  
- Инициализация браузера Chrome в headless-режиме
- Загрузка главной страницы Habr
- Поиск блока со статьями и получение списка статей
- Для каждой статьи:
* Извлечение заголовка, ссылки, даты и превью-текста
* Проверка наличия ключевых слов в заголовке или тексте
* Добавление в результат при совпадении
* Вывод результатов в консоль
- Сохранение результатов в JSON-файл

## Используемые технологии
- Selenium WebDriver - для автоматизации браузера
- ChromeDriver - драйвер для управления Chrome
- WebDriver Manager - автоматическое управление драйвером
- JSON - для сохранения результатов
